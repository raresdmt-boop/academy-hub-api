# Academy Hub API

A Spring Boot application for managing students, courses,
enrollments and books.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Jakarta Validation

## Features

- Student management
- Course management
- Student enrollments
- Book management
- JPA entity relationships
- Custom database queries

## Project Structure

The application follows a layered architecture:

- Models
- DTOs
- Repositories
- Services
- Controllers
